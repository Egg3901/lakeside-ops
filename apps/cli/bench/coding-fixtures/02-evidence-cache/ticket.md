# Ticket: duplicated lookups and stale evidence after invalidation
Repair src/cache.cjs, preserving createEvidenceCache({load, ttlMs, now}) returning {get, invalidate, clear}. now defaults to Date.now.
get(key) returns a Promise. Concurrent gets for the same key share one in-flight load; keys remain independent. A successful load (including undefined) is cached for ttlMs measured from completion, with age >= ttlMs expired. A rejection must be propagated and evicted so a later get retries. invalidate(key) evicts cached and pending entries for that key; an earlier pending caller may receive its result, but that old result must neither populate the cache nor remove a newer in-flight request. clear applies the same rule to every key. No background polling or timers are needed. Loads must receive the exact key. Mutating a returned value is outside scope.
Run node --test public.test.cjs. Hidden checks exercise races, expiration boundaries, rejections and multiple keys. Do not change API or tests, install dependencies, or use a global cache shared between instances.
